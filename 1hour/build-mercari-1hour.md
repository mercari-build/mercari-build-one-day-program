## このプログラミング体験でやること

やることは、たった **3 つ** です。

| | やること | 説明 |
| :-: | --- | --- |
| 1️⃣ | **ブロックをならべる** | 「点数 +1」のようなブロックを、ドラッグしてならべます |
| 2️⃣ | **コードが自動でできる** | ならべたブロックが、そのまま右側の**本物のコード**になります |
| 3️⃣ | **ゲームが変わる** | 変えたらすぐ、まん中のゲームの動きが変わります |

![3ステップの流れ](images/intro-3steps.png)

> 💡 **むずかしい文字を打つ必要はありません。** ブロックをならべるだけで、プロのエンジニアが書くのと同じ形のコードができます。

### ゴール

**「自分がならべたブロックで、ゲームのルールが変わる」のを体験すること。**

- 上手につくることより、**まず動かしてみる**ことが大事です
- 「なんかヘンな動きになった」も大成功。それも自分でつくったルールです
- わからなくなったら、**すぐメンターに聞いてください**

## ステップ 1：ブロックを 1 個おいてみる

最初は **これだけ** やってみましょう。

### やること

1. 左上の **`点数 +1`** ブロックを見つける
2. それを **🍎 キャッチしたとき** の枠まで **ドラッグ**する
   （ドラッグがむずかしければ、**ブロックをクリックするだけ**でも入ります）
3. マウスを動かして、かごでりんごをキャッチしてみる

<!-- ![点数+1 をキャッチしたときにドラッグする](images/step1-drag.png) ← 画像ができたら、この行のコメント記号をはずす -->

### できたかどうかの確認

- **Score** の数字が増えた ✅
- 右の **コード**に、1 行増えた ✅

<!-- ![Score が増えて、コードに行が増えた](images/step1-score-up.png) ← 画像ができたら、この行のコメント記号をはずす -->

🎉 **おめでとう！これがプログラミングです。**
「キャッチしたら点数を 1 増やす」というルールを、自分でつくりました。

### つぎに、いろいろ試してみよう

`点数 +1` を消して、ほかのブロックに変えてみましょう。

- `点数 × 2` にしたら？ → …あれ、ずっと 0 のままだ。**なぜだと思う？**
- `点数 + 5` にしたら？ → 一気にスコアがのびる
- `スピードUP` を足したら？ → だんだん速くなって、むずかしくなる

<details>
<summary>💭 「点数 × 2」が 0 のままな理由（考えてから開こう）</summary>

点数は **0 からはじまります**。そして **0 × 2 = 0**。
何回キャッチしても、0 を 2 倍しているだけなので、ずっと 0 のままです。

だから `点数 × 2` を使うときは、**先に `点数 +1` をおいて** 点数を 0 より大きくしておく必要があります。
`点数 +1` → `点数 × 2` の順にならべてみてください。一気にのびます。

</details>

> 💡 **2 個以上ならべてもOK。** 上から順番に実行されます。
> たとえば `点数 +1` と `スピードUP` をならべると、「点数が増えて、しかも速くなる」ゲームになります。

## ステップ 2：のがしたときを決める

いまのままだと、りんごをのがしても **なにも起きません**。
ここに **ペナルティ（バツ）** をつけると、ゲームらしくなります。

### やること

1. **`点数 − 1`** を **💧 のがしたとき** の枠にドラッグする
2. わざと 1 個のがしてみる → Score が減る

<!-- ![点数−1 をのがしたときにドラッグする](images/step2-drag-minus.png) ← 画像ができたら、この行のコメント記号をはずす -->

### 試してみよう

| ならべるブロック | どんなゲームになる？ |
| --- | --- |
| `点数 − 1` | やさしめ。ちょっと損するだけ |
| `点数 − 3` | きびしい。集中しないとすぐ減る |
| `点数を 0 に` | **超きびしい。** 1 回のがしたら全部パー |
| （からっぽ） | ゆるゆる。のがしても平気 |

> 💡 **ゲームバランス**を決めているのは、いま自分です。
> むずかしすぎても、かんたんすぎても、おもしろくありません。**自分がちょうどいいと思う数字**をさがしてみてください。

## ステップ 3：WIN と TRY AGAIN をつける

まだ、このゲームには **終わりがありません**。
「もし ○○ なら 終わり」という **勝ち負けの条件** をつけましょう。

### 「もし」ブロック

左の **WIN / TRY AGAIN** のところにある、まるいブロックです。

| ブロック | 意味 |
| --- | --- |
| 🟢 `もし 点数が 20 以上なら WIN!` | 20 点とれたら勝ち |
| 🔴 `もし 点数が 0 以下なら TRY AGAIN` | 点数がなくなったら負け |
| 🔴 `もし のがしが 5 以上なら TRY AGAIN` | 5 回のがしたら負け |

![WIN / TRY AGAIN のブロック](images/step3-win-blocks.png)

### やること

1. `もし 点数が 20 以上なら WIN!` を **🍎 キャッチしたとき** にドラッグする
   - ⚠️ 大事：**`点数 +1` の下**におきます（理由はこのあとのクイズで！）
2. `もし のがしが 5 以上なら TRY AGAIN` を **💧 のがしたとき** にドラッグする
3. あそんでみる → 20 点で **WIN!**、5 回のがすと **TRY AGAIN**

<!-- ![WINしたゲーム画面](images/step3-win.png) ← 画像ができたら、この行のコメント記号をはずす -->
<!-- ![TRY AGAINのゲーム画面](images/step3-tryagain.png) ← 画像ができたら、この行のコメント記号をはずす -->

### 順番はとても大事

コードは **上から順番に** 実行されます。だから、**ならべる順番で結果が変わります。**

ここでクイズです。さっきは **A** の順にならべてもらいました。
もし **B** のように逆にならべたら、どうなると思いますか？

- **A**： `点数 +1` → `もし 点数が 20 以上なら WIN!`
- **B**： `もし 点数が 20 以上なら WIN!` → `点数 +1`

<details>
<summary>💭 こたえを見る（B もじっさいにためしてから開こう）</summary>

**B だと、勝つのが 1 回おそくなります。**

B では、点数を増やす **前**に「20 点いった？」と聞いてしまいます。
だから 20 個目をキャッチした瞬間は、まだ **19 点**として判定され、勝てません。
そのあと **21 個目**をとったときに、やっと WIN! になります。

| ならべ方 | どうなる？ |
| --- | --- |
| **A**：`点数 +1` → `もし 20 以上なら WIN!` | ✅ ちょうど 20 点で勝てる |
| **B**：`もし 20 以上なら WIN!` → `点数 +1` | ⚠️ 21 点にならないと勝てない |

</details>

> 💡 これは **バグ**の原因でいちばん多いやつです。「動きがヘンだな」と思ったら、**ならべた順番**をうたがってみてください。

## ステップ 4：みためを変える

ルールができたら、色を変えて **自分のゲーム**にしていきましょう。
右上の **🎨 みため** タブをひらきます。

![みためタブ](images/step4-css-tab.png)

ここだけは、ブロックではなく **自分で文字を打ちかえます**。
書いてあるのは **CSS（シーエスエス）** という、**見ため専用の言語**です。

> 😌 CSS はゲームのルールとは **別もの**なので、ここをいじってもゲームは壊れません。
> どんどんためしてみてください。

### まず変えられるのは、この 3 つ

| どこ | 変わるもの |
| --- | --- |
| `background:` の `#ffd6a5` みたいな文字 | 背景の色 |
| `border-radius: 16px` の数字 | ゲーム画面の **かどのまるさ** |
| `box-shadow: ...` | ゲーム画面の **かげ** |

### やること：背景の色を変える

1. `#ffd6a5` のように **`#` からはじまる 6 文字** をさがす
2. それを別の色に打ちかえる（下の表からコピーでOK）
3. すぐに背景の色が変わる 🎉

`#` のあとの 6 文字は **カラーコード**といって、**色につけられた番号**です。
世界中のウェブサイトが、この番号で色を決めています。

#### そのまま使える色

`background:` の中には、カラーコードが **3 つ**ならんでいます。

```css
background: linear-gradient(135deg, #ffd6a5 10%, #ffadad 50%, #fdffb6 100%);
/*                                  ↑1つめ      ↑2つめ      ↑3つめ        */
```

この 3 つが上から下へまざり合って、グラデーションになっています。
**3 つとも**、下の表の色に打ちかえてみてください。

| テーマ | 1 つめ | 2 つめ | 3 つめ |
| --- | --- | --- | --- |
| 🌅 夕やけ（さいしょの色） | `#ffd6a5` | `#ffadad` | `#fdffb6` |
| 🌌 夜空 | `#1e3a8a` | `#312e81` | `#4c1d95` |
| 🌊 海のなか | `#caf0f8` | `#48cae4` | `#0077b6` |
| 🌿 森 | `#d8f3dc` | `#95d5b2` | `#2d6a4f` |
| 🍓 いちご | `#ffccd5` | `#ff8fa3` | `#c9184a` |
| 🌸 ゆめかわ | `#ffc8dd` | `#bde0fe` | `#cdb4db` |
| 🌇 ネオン | `#f72585` | `#7209b7` | `#3a0ca3` |
| 🖤 モノクロ | `#e9ecef` | `#adb5bd` | `#343a40` |

> 💡 **1 つだけ変えてもOK。** まず 1 つめだけ変えて、どこが変わるか見てみるのがおすすめです。

<!-- ![色を変えたゲーム画面](images/step4-color.png) ← 画像ができたら、この行のコメント記号をはずす -->

### もっとやってみる

| いじるところ | やってみること |
| --- | --- |
| `border-radius: 16px` | `0px` で **かくかく**、`50px` で **まるまる** |
| `box-shadow` の `0.25` | `0.6` にすると、かげが **こくなる** |
| `135deg` | `0deg` や `90deg` に変えると、グラデーションの **向き**が変わる |
| `10%` `50%` `100%` | 色が切りかわる **位置**。`50%` を `20%` にすると 2 つめの色が上に寄る |

> ⚠️ **打ちまちがえると、反映されなくなります。**
> 原因のほとんどは、`;`（セミコロン）や `:`（コロン）、`{ }` をうっかり消してしまうこと。
> それと、**かならず半角で打つこと**（`＃` や `；` のような全角だと動きません）。
> 直せなくなったら、遠慮なくメンターを呼んでください。

## 発展：自分で CSS を書き足してみよう

ここまで終わった人へ。**表に書いてないことも、自分で書き足せます。**

やり方はいつも同じで、`canvas { }` か `body { }` の **`{ }` の中に 1 行足す**だけです。

```css
canvas {
  border-radius: 16px;
  box-shadow: 0 12px 36px rgba(90, 58, 46, 0.25);
  ここに 1 行足す;        ← こういうこと
}
```

> 💡 **1 個ずつ足して、そのたびに画面を見る。** これがいちばん速いやり方です。
> いっぺんに 3 個足すと、どれが効いたのか分からなくなります。

### ① りんごの色まで変える 🍎 → 🫐

**`canvas { }` の中**に足す:

```css
filter: hue-rotate(120deg);
```

ゲーム画面の色が **ぜんぶ**グルッと変わります。**りんごの色も変わります。**
`120deg` を `0` 〜 `360` で変えて、好きな色をさがしてみてください。

ほかにもこんなのがあります。

| 書くもの | どうなる？ |
| --- | --- |
| `filter: invert(1);` | 色が反転（ネガフィルムみたい） |
| `filter: saturate(3);` | 色がド派手になる |
| `filter: grayscale(1);` | 白黒（モノクロ映画みたい） |
| `filter: blur(2px);` | ぼやける（激ムズになるので注意！） |

### ② ゲーム画面にわくをつける

**`canvas { }` の中**に足す:

```css
border: 8px solid #ffffff;
```

`8px` が太さ、`#ffffff` が色。`solid` を `dashed` にすると点線のわくになります。

> 💡 白がぼんやりして見えにくいときは、**こい色**（`#3a0ca3` など）にすると、はっきりします。

### ③ しま模様の背景にする

**`body { }` の `background:` の行**を、これに書きかえる:

```css
background: repeating-linear-gradient(45deg, #ffd6a5 0 40px, #ffadad 40px 80px);
```

`linear-gradient` を `repeating-linear-gradient` にすると、**同じ模様がくりかえし**ならびます。
`40px` を `10px` にすると細いしま、`100px` にすると太いしまになります。

### ④ 丸いグラデーションにする

同じく **`background:` の行**を書きかえる:

```css
background: radial-gradient(circle, #fdffb6, #ffadad, #f72585);
```

`linear`（まっすぐ）ではなく `radial`（丸く）ひろがります。

### ⑤ マウスの形を変える

**`canvas { }` の中**に足す:

```css
cursor: crosshair;
```

`crosshair`（十字）のほかに `pointer`（指）、`grab`（つかむ手）、`none`（見えなくなる！）が使えます。

### ⑥ ゲーム画面をふわふわ浮かせる

これは少し長いです。**いちばん下**（`}` の外）に足してください:

```css
@keyframes fuwafuwa {
  0%   { transform: translateY(0); }
  50%  { transform: translateY(-12px); }
  100% { transform: translateY(0); }
}

canvas {
  animation: fuwafuwa 2s ease-in-out infinite;
}
```

`@keyframes` は「アニメーションの手順書」です。
`0%`（はじめ）→ `50%`（まん中）→ `100%`（おわり）で、どこにいるかを書いています。
`2s` は 2 秒で 1 往復、`infinite` は「ずっとくりかえす」という意味。

> 🎢 **おまけ（バグるかも）：** `canvas { }` に `transform: rotate(5deg);` を足すと画面がかたむきます。
> おもしろいけど、**かごがマウスとズレる**ことがあります。ズレたら、足した行を消せば元に戻ります。

### 自分で調べてみる

やりたいことが決まっているなら、**検索するのがいちばん速い**です。
エンジニアも毎日ふつうに検索しています。

- 「**css 角を丸くする**」

## コードのよみかた

右側のコードは、ブロックをおけば **自動でできる**ので、書かなくても大丈夫。
でも **読めるとかっこいい**です。3 つだけ覚えれば、だいたい読めます。
（自分で書きかえたい人は、このあとの [発展：コードを直接書きかえてみよう](#発展コードを直接書きかえてみよう) へ）

### ① `function`（ファンクション）＝「〜したときの、やることリスト」

```javascript
// 🍎 をキャッチしたとき、上から順に実行する
function onCatch() {
  // ← ここに、キャッチしたときのブロックが入る
}
```

- `onCatch` = **on（〜したとき）＋ catch（キャッチ）** → 「キャッチしたとき」
- `onMiss` = **on ＋ miss（のがす）** → 「のがしたとき」
- `{` と `}` のあいだが、**やることリストの中身**です

### ② 上から順番に実行される

`{` から `}` まで、**上の行から下の行へ**、順番に実行されます。
だから左でブロックをならべた順番が、そのままコードの順番になります。

### ③ `if`（イフ）＝「もし〜なら」

`もし 点数が 20 以上なら WIN!` のブロックは、コードだと `if` になります。
「もし条件があてはまったら、`{ }` の中をやる」という意味です。

### ④ `//` からうしろは、コンピュータが読まない

`//` で始まる行は **コメント**といって、**人間が読むためのメモ**です。
プログラムの動きには影響しません。

> 💡 **ブロックを 1 個おいて、コードのどこが増えたか見くらべてみてください。** それが「自分が書いたコード」です。

### おまけ：2 つの言語を使っています

今日つかった 2 つのタブは、じつは **べつべつの言語**です。プロの現場でも、この 2 つを使い分けています。

| タブ | 言語 | やくわり |
| --- | --- | --- |
| ✏️ コード | **JavaScript** | ゲームの **ルール**（どう動くか）を決める |
| 🎨 みため | **CSS** | **見ため**（色や形）を決める |

## 発展：コードを直接書きかえてみよう

みため（CSS）だけでなく、**ゲームのルールそのもの**も自分で書きかえられます。
ここまで来たら、**ブロックには無い、自分だけのルール**が作れます。

### ⚠️ さきに、大事な約束

コードは **ブロックから自動で作られています**。だから、やる順番がとても大事。

1. **さきに**、ブロックでルールを作る（ステップ 1〜3）
2. **そのあとで**、コードを書き足す

> 🚨 **コードを書いたあとにブロックをいじると、書いたコードは消えます。**
> ブロック → コードの **一方通行**だからです。
> 消えても失敗ではありません（そういう作りです）。もう一度書けば大丈夫。
> 心配な人は、書いたコードを **メモアプリにコピーしておく**と安心です。

### 💡 最強のコツ：ブロックを「辞書」として使う

書きかたが分からなくなったら、**そのブロックを 1 個おいて、できたコードを見る。**
それがそのまま **お手本**になります。写して使えばOKです。

> 例：スピードを変える書きかたが分からない → `スピードUP` を 1 個おいて、できた行を見る

### ① ランダムな点数にする 🎲

`点数 +1` が作った行を、これに書きかえる:

```javascript
score = score + Math.floor(Math.random() * 5) + 1;
```

キャッチするたびに、**1〜5 点**がランダムで入ります。

- `Math.random()` は **0 以上 1 未満のランダムな小数**を作る
- `* 5` して `Math.floor()`（切りすて）で **0〜4**
- `+ 1` して **1〜5** になる

> 🎯 `5` を `100` にすると、1 回で 100 点入ることもあります。

### ② 点数が偶数のときだけボーナス ✌️

`onCatch()` の中に:

```javascript
if (score % 2 === 0) {
  score = score + 2;
}
```

`%` は **わり算のあまり**。`score % 2` が `0` なら偶数（2 でわり切れる）です。

> `===` は「**同じかどうか**」を調べる記号。`=` 1 個は「**入れる**」なので、別ものです。

### ③ れんぞくボーナス（コンボ）🔥

**これはブロックでは作れません。** コードだからできるルールです。

まず、コードの **いちばん上**（`function` より前）に 1 行:

```javascript
let combo = 0;
```

`onCatch()` の `{ }` の中:

```javascript
combo = combo + 1;
score = score + 1;
if (combo >= 3) {
  score = score + 5;
  combo = 0;
}
```

`onMiss()` の `{ }` の中:

```javascript
combo = 0;
```

3 個れんぞくでキャッチすると **+5 点**。1 個でものがすと 0 に戻ります。

`let` は「**新しい入れものを作る**」という意味。
`combo` という入れものが、**いま何個れんぞくなのか**を覚えてくれています。

### ④ 最初の 1 回だけ大ボーナス 🎁

いちばん上に:

```javascript
let firstCatch = true;
```

`onCatch()` の中に:

```javascript
if (firstCatch === true) {
  score = score + 10;
  firstCatch = false;
}
```

`true` / `false` は「**はい / いいえ**」だけを覚えておける入れもの。
1 回使ったら `false` にするので、**2 回目からは入りません**。



### ⑤ 点数が増えるほど、むずかしくする 📈

`onCatch()` の中に:

```javascript
if (score >= 10) {
  // ここに「スピードUP」ブロックが作る行を貼る
}
```

「10 点をこえたら、キャッチするたびに速くなる」＝ **だんだん本気になるゲーム**。
`{ }` の中に貼る行は、`スピードUP` を 1 個おいて確認してください（さっきの「辞書」のコツ）。

### ⑥ のがすほど、やさしくする 🤝

⑤ の逆を、`onMiss()` の中に書きます。
`スピードUP` が作った行をコピーして、**`+` を `-` に変える**だけ。

苦戦している人ほどやさしくなるので、**あきらめずに続けられるゲーム**になります。
（プロのゲームでも実際に使われている工夫です）

> 🎉 **ブロックに無いルールを作れたら、それはもう「自分だけのゲーム」です。**

## こまったとき

### よくある「あれ？」

| こうなった | たぶんこれ |
| --- | --- |
| ブロックをおいても、なにも起きない | **置き場所**がちがうかも（キャッチ／のがしを確認） |
| Score が増えない | 🍎 キャッチしたとき が **からっぽ**かも |
| `点数 × 2` にしたのに増えない | **0 × 2 = 0** だから。`点数 +1` を先におこう |
| すぐ TRY AGAIN になる | ペナルティが強すぎるかも（`点数を 0 に` → `点数 − 1` に変えてみる） |
| りんごが速すぎる | `スピードUP` を消してみる |
| みためを変えたのに、なにも変わらない | **全角**の文字が混ざってるかも。`;` `:` `#` `{ }` を消してないかも確認 |
| 自分で書いたコードが消えた | ブロックをいじると、コードは自動生成でリセットされます。**ブロックは先、コードはあと** |
| ぜんぶ元に戻したい | `クリア`を押す。元に戻せないので注意！ |

### メンターを呼ぶとき

**遠慮しないで、すぐ呼んでください。** ひとりで止まっている時間がいちばんもったいないです。

こう伝えると、原因がすぐ見つかります。

> 1. **なにをしたら**（例：「点数 +1 をキャッチしたときに入れたら」）
> 2. **どうなったか**（例：「Score が増えなかった」）
> 3. **どうなってほしかったか**（例：「1 ずつ増えてほしかった」）
